1项目概述

Stock Buddy 是一个面向 A 股市场的智能投资辅助系统，旨在为个人投资者提供专业级的市场分析、个股诊断、技术分析和持仓监控能力。

📊

市场热点分析

板块轮动追踪、涨停梯队复盘、资金流向热力图、题材驱动分析，帮助投资者快速锁定市场主线。

🔍

个股综合诊断

基本面 + 技术面 + 资金面 + 消息面四维诊断模型，输出结构化风险评估与投资价值评分。

📈

技术分析引擎

支撑位/压力位自动识别、20+ 技术指标计算（MACD/KDJ/布林带/RSI 等）、趋势形态识别。

🔔

持仓监控告警

自选股实时监控、价格/指标异动告警、止损止盈提醒、板块资金异动推送。

💰

资金流向分析

主力资金净流入/流出追踪、北向资金动向、行业资金分布、龙虎榜数据解析。

🧠

AI 辅助决策

基于规则引擎 + 量化模型的智能选股、风险预警和操作建议生成。

架构设计原则

  • 分层解耦：前端、API、业务逻辑、数据采集、存储各层职责清晰，通过 trait 接口通信
  • 数据驱动：统一的数据模型和采集管道，所有业务模块共享标准化数据
  • 实时 + 离线：盘中实时推送 + 盘后批量分析，双通道并行
  • 可扩展：数据源适配器模式，新增数据源只需实现 trait 接口；策略插件化
  • 高性能：Rust 零成本抽象 + 异步 IO (tokio)，支撑高并发数据采集与计算

3技术选型

以 Rust 为核心，构建高性能、类型安全、内存安全的后端服务。

组件选型选择理由
编程语言 Rust 高性能、内存安全、强类型系统；Rustrover 原生支持；适合金融数据处理场景
异步运行时 Tokio Rust 生态最成熟的异步运行时，支持高并发 IO 密集型任务
Web 框架 Axum Tokio 团队官方维护，与 Tower 中间件生态无缝集成，类型安全路由

4核心模块设计

六大核心业务模块 + 两大基础设施模块，各模块通过 trait 接口解耦。

4.1 数据采集模块 (DataFetcher)

统一数据采集管道

  • 多源适配器：为每个数据源实现 DataFetcher trait，支持统一接口切换
  • 实时行情：东方财富 Push2 API 轮询/WebSocket，3-5 秒刷新频率
  • 历史 K 线：日/周/月 K 线数据，支持前复权/后复权
  • 财务数据：资产负债表、利润表、现金流量表，季报/年报
  • 资金数据：主力资金流向、北向资金、龙虎榜、大宗交易
  • 新闻公告：个股新闻、公司公告、研报摘要
  • 定时调度：基于 cron 表达式的任务调度，盘前/盘中/盘后不同策略

4.2 市场热点分析模块 (MarketAnalyzer)

市场全景扫描

  • 板块轮动：申万一级/二级行业涨跌排行，板块资金净流入排名
  • 涨停梯队：连板天数分层统计、炸板率计算、晋级率追踪
  • 题材驱动：热点题材识别、关联个股挖掘、题材强度评分
  • 市场情绪：涨跌家数比、涨停跌停比、连板高度、情绪温度计
  • 龙虎榜：游资席位追踪、机构买卖统计、知名游资动向

4.3 个股诊断模块 (StockDiagnoser)

四维诊断模型

  • 基本面：PE/PB/PS 估值分位、ROE/营收增速/利润增速趋势、负债率、现金流健康度
  • 技术面：趋势方向（均线多头/空头排列）、量价配合度、形态识别
  • 资金面：主力资金近 5/10/20 日净流入、北向持仓变化、融资融券余额变化
  • 消息面：近期利空/利好事件、解禁/减持/回购公告、业绩预告
  • 综合评分：0-100 分制综合评分 + 风险等级（低/中/高）+ 操作建议

4.4 技术分析引擎 (TechnicalAnalyzer)

专业级技术分析

  • 支撑/压力位：基于近期高低点、筹码分布、整数关口、均线位的综合计算
  • 技术指标库：MACD、KDJ、RSI、布林带、OBV、CCI、WR、DMI 等 20+ 指标
  • 形态识别：头肩顶/底、双顶/双底、三角形、旗形等经典形态自动识别
  • K 线形态：十字星、锤子线、吞没形态、早晨之星/黄昏之星等
  • 趋势分析：道氏理论、波浪理论辅助标注、趋势线自动绘制
  • 筹码分布：基于成交量分布的筹码峰计算，支撑/压力可视化

4.5 资金流向模块 (CapitalFlow)

资金动向全景

  • 个股资金：超大单/大单/中单/小单资金流向，主力净买额趋势
  • 板块资金：行业/概念板块资金净流入排行，板块轮动资金信号
  • 北向资金：沪深股通实时净买额、十大活跃股、行业配置变化
  • 融资融券：融资余额变化趋势、融券卖出变化、多空力量对比
  • 大宗交易：折溢价率统计、机构大宗交易追踪

4.6 监控告警模块 (Monitor & Alert)

智能告警系统

  • 价格告警：突破/跌破指定价格、涨跌幅阈值、日内振幅异常
  • 指标告警：MACD 金叉/死叉、KDJ 超买/超卖、均线突破/跌破
  • 量价告警：放量涨停、缩量跌停、量比异常放大
  • 资金告警：主力大额净流入/流出、北向资金异动
  • 事件告警：公告/新闻关键词触发、停复牌通知
  • 推送渠道：站内消息、WebSocket 实时推送、邮件通知（可选微信/钉钉）

4.7 数据存储模块 (Storage)

分层存储策略

  • 热数据：Redis 缓存实时行情、自选股列表、会话信息（TTL 5-10 秒）
  • 温数据：数据库存储日 K 线、财务数据、诊断报告（持久化）
  • 冷数据：历史 Tick 数据、分钟 K 线归档（按需查询）
  • 时序优化：K 线数据按 (股票代码, 日期) 复合索引，支持快速范围查询

4.8 调度与任务模块 (Scheduler)

定时任务调度

  • 盘前任务（09:00-09:25）：获取昨日收盘数据、更新股票列表、计算隔夜信号
  • 盘中任务（09:25-15:00）：实时行情采集、指标计算、告警检测、资金流监控
  • 盘后任务（15:00-23:00）：日线数据更新、龙虎榜解析、涨停复盘、诊断报告生成
  • 周末任务：周线数据更新、板块统计、策略回测

关键数据流场景

7API 设计

RESTful API + WebSocket 双通道，统一 /api/v1 前缀，JSON 格式交互。

REST API 接口

行情数据

GET /api/v1/quotes/{stock_code}

获取个股实时行情（最新价、涨跌幅、成交量等）

GET /api/v1/quotes/batch?codes=000001,000002,...

批量获取多只股票实时行情

GET /api/v1/kline/{stock_code}?period=daily&start=2026-01-01&end=2026-08-01

获取 K 线数据，支持 daily/weekly/monthly/minute

市场分析

GET /api/v1/market/overview

大盘总览（上证/深证/创业板指数、涨跌家数、市场情绪）

GET /api/v1/market/sectors?type=industry&sort=change_pct

板块排行（行业/概念板块涨跌排行）

GET /api/v1/market/limit-up?date=2026-08-01

涨停板复盘（连板梯队、炸板统计、晋级率）

GET /api/v1/market/dragon-tiger?date=2026-08-01

龙虎榜数据（游资席位、机构买卖）

个股诊断

GET /api/v1/diagnosis/{stock_code}

获取最新诊断报告（综合评分、风险等级、四维分析详情）

POST /api/v1/diagnosis/{stock_code}/generate

触发生成新的诊断报告（实时计算）

技术分析

GET /api/v1/technical/{stock_code}/indicators?types=macd,kdj,rsi,boll

获取技术指标计算结果

GET /api/v1/technical/{stock_code}/support-resistance

获取支撑位/压力位分析

GET /api/v1/technical/{stock_code}/patterns

获取 K 线形态/技术形态识别结果

GET /api/v1/technical/{stock_code}/chip-distribution

获取筹码分布数据

资金流向

GET /api/v1/capital/{stock_code}/flow?days=10

个股资金流向（主力/超大单/大单/中单/小单）

GET /api/v1/capital/north?days=30

北向资金数据（净买额、十大活跃股）

GET /api/v1/capital/sector-flow?type=industry

板块资金流向排行

自选股 & 告警

GET /api/v1/watchlist

获取自选股列表

POST /api/v1/watchlist

添加自选股

POST /api/v1/alerts/rules

创建告警规则

GET /api/v1/alerts/history?status=unread

获取告警历史

WebSocket 接口

WS /ws/quotes?codes=000001,600000

订阅实时行情推送（3-5 秒频率）

WS /ws/alerts

订阅告警推送（价格突破、指标信号等实时通知）

9开发路线图

分四个阶段迭代开发，每个阶段产出可用的增量版本。

Phase 1 · 基础设施

项目骨架 + 数据采集 + 行情展示

搭建 Cargo Workspace 项目骨架；实现东方财富/新浪数据采集适配器；完成数据库 schema 设计与迁移；实现基础 REST API（行情、K 线）；搭建 React 前端骨架，实现 K 线图展示和实时行情面板。
交付物：可运行的 Web 应用，能查看个股实时行情和 K 线图。

Phase 2 · 核心分析

技术分析引擎 + 个股诊断

实现技术指标计算库（MACD/KDJ/RSI/布林带等 20+ 指标）；支撑位/压力位算法；K 线形态识别；个股四维诊断模型（基本面/技术面/资金面/消息面）；诊断报告生成与展示。
交付物：个股诊断页面、技术分析页面（指标叠加、形态标注）。

Phase 3 · 市场全景

市场热点 + 资金流向 + 涨停复盘

板块轮动分析；涨停梯队统计与复盘；龙虎榜数据解析；资金流向分析（主力/北向/融资融券）；市场情绪指标；大盘仪表盘。
交付物：市场热点页面、资金流向页面、涨停复盘日报。

Phase 4 · 智能告警

自选股管理 + 告警系统 + WebSocket 推送

自选股分组管理；告警规则引擎（价格/指标/资金/事件）；WebSocket 实时推送；告警历史记录；邮件/Webhook 通知；Docker 容器化部署。
